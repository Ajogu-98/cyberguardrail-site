# CyberGuardrail Website

Cybersecurity consulting website built with React + Vite, deployed on Netlify.

## Local Development

```bash
npm install
npm run dev
```

Opens at http://localhost:5173

## Build for Production

```bash
npm run build
```

Output goes to `dist/` folder.

## Deployment

This site is configured for Netlify deployment. See `netlify.toml` for build settings.
